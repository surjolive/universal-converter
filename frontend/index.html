Troubleshooting

Why does the detected format differ from the filename?

The converter checks file signatures as well as extensions. A file named .php that begins with a PDF signature is treated as a PDF.

Why is an output format missing?

Only registered routes are offered for the detected source. Some routes also need optional tools; check the Engines page for their status.

Where are my files processed?

Uploads and conversions are processed by this local application. Generated files and history remain in its local storage.

How does image background removal work?

It makes flat-color regions connected to the image edge transparent. Choose PNG output; it is not intended for complex backgrounds.
