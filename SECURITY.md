# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Email [surjolivemailbox@gmail.com](mailto:surjolivemailbox@gmail.com) with a description, affected version, impact, and steps to reproduce. Do not attach private files or sensitive user data.

## Application safeguards

- The local API binds to loopback by default.
- Uploaded source files are not executed automatically.
- User settings, uploads, generated files, and the local database remain in local application storage and are not part of this repository.
